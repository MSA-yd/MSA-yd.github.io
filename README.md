# Yidong Ming — Academic Homepage

Website: https://msa-yd.github.io/

Static HTML site published from `main`, repository root.

- `index.html`: profile links, research, publications, experience, and awards.
- `style.css`: layout and appearance.
- `script.js`: active section navigation.
- `files/yidong-ming-cv.pdf`: current CV.
- `assets/`: research figures.

Full texts of the two manuscripts under review and the application research summary are excluded. Those materials are shared separately for applications.

No build or dependencies are required. `.nojekyll` tells GitHub Pages to serve the static files directly.
